# bank_marketing_project
This project compares customer information, campaign history, and economic indicators for predicting term-deposit subscriptions.

## Data
Download the UCI Bank Marketing dataset:
https://archive.ics.uci.edu/dataset/222/bank+marketing
Extract bank-additional-full.csv and put it in the same folder as baseline.ipynb.

The dataset is licensed under CC BY 4.0. Credit: Moro, Rita, and Cortez (2014).

## Run
Install Python packages: pandas, numpy, matplotlib, and scikit-learn.
Open baseline.ipynb in Jupyter or VS Code and run all cells from top to bottom.
